
# Bank Loan Analysis – Exploratory Data Analysis

## Project Overview

This project explores bank loan data to understand loan applications, borrower characteristics, loan status, and repayment-related patterns.

## Objectives

* Analyze loan application and borrower data.
* Perform data cleaning and exploratory data analysis.
* Identify patterns and trends using visualizations.
* Present meaningful insights from the dataset.

## Tools & Technologies

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Jupyter Notebook / Google Colab

## Project Workflow

1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Data visualization
5. Key findings and conclusions
